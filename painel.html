Sincronização privada com GitHub recomendado

Use um repositório privado separado (por exemplo, festa-ben-dados). Assim convidados, telefones, orçamento e confirmações não ficam publicados junto com o convite. O token permanece somente neste navegador.

Como criar o token (passo a passo)
  1. Abra github.com/settings/tokens?type=beta ↗ (é nas configurações da sua conta, no canto superior direito do GitHub — não é nas configurações do repositório)
  2. Clique em Generate new token.
  3. Crie antes um novo repositório privado, por exemplo festa-ben-dados.
  4. Em Repository access, escolha Only select repositories e marque somente esse repositório privado.
  5. Em Permissions → Repository permissions, coloque Contents em Read and write.
  6. Gere o token, copie o valor (github_pat_…) e cole no campo abaixo.
