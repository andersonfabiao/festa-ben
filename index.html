Sincronização com GitHub opcional

Assim você abre a página em qualquer aparelho e vê os mesmos dados. O token fica salvo somente neste navegador — ele nunca vai para o repositório.

Como criar o token (passo a passo)
  1. Abra github.com/settings/tokens?type=beta ↗ (é nas configurações da sua conta, no canto superior direito do GitHub — não é nas configurações do repositório)
  2. Clique em Generate new token.
  3. Em Repository access, escolha Only select repositories e marque o repositório da festa.
  4. Em Permissions → Repository permissions, coloque Contents em Read and write.
  5. Gere o token, copie o valor (github_pat_…) e cole no campo abaixo.
